旺销王质检放大助手 v0.6.2 — 重新加载即可检查更新

【首次安装】
1. 完整解压 ZIP，双击“安装或升级.cmd”。安装器放置完整插件及本机更新组件，无需管理员权限、Codex 或 Python。
安装窗口会保留结果：看到绿色“安装成功”和版本号后，按任意键关闭。
如果显示“安装未完成”或红色错误，请保留窗口，将最后几行拍照用于排查。安装记录保存在 %LOCALAPPDATA%\WxwQcHelper-Setup。
2. 在 Edge 打开 edge://extensions/，开启“开发人员模式”并保持开启。
3. 点击“加载解压缩的扩展”，选择下面的文件夹：
   %LOCALAPPDATA%\WxwQcHelper\extension
4. 把助手固定到工具栏。首次加载会自动检查一次线上版本。
5. 图标出现 OK 后刷新旺销王扫码页，即可正常使用。出现 ! 代表更新未完成，离线安装的当前版本仍可使用。

【以后更新】
在两单之间，打开 Edge 扩展管理页，点击助手的“重新加载”。
助手自动检查、下载、验证、备份和替换新版，并自动再加载一次使新版生效。
等待图标出现 OK，再手动刷新旺销王扫码页；不会自动刷新业务页或重复扫码。
也可以点助手弹窗里的“检查并应用更新”。不需要先点桌面快捷方式。

【网络条件】
更新来自公开 GitHub，不需要 GitHub 账号。但那台电脑必须能访问 GitHub 下载地址。
没有 VPN 不代表一定失败，也不代表一定成功；尚未验证质检电脑的网络。
网络失败会显示 !，保留已安装版本。扫码放大功能不需要 GitHub。

安装器不创建桌面更新或回退快捷方式，并清理之前由本助手生成的两项旧快捷方式。

【本机组件】
固定目录：%LOCALAPPDATA%\WxwQcHelper
安装器为当前 Windows 用户注册 Edge 原生消息组件 com.wxw.qc.updater，只允许这个助手调用。
组件只接受更新动作，不接受网页提供的命令或下载地址；签名、哈希和失败恢复继续生效。
不修改浏览器管理策略，不建立定时任务或常驻服务。使用结束后组件自动退出。
请保留固定目录；最初下载的 ZIP 和解压目录安装后可删除。

【卸载】
在 Edge 移除助手后，可删除固定目录。
原生消息登记位于 HKCU\Software\Microsoft\Edge\NativeMessagingHosts\com.wxw.qc.updater；删除对应这一项即可清理登记。
