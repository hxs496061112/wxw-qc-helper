旺销王质检放大助手 — 在线更新版 v0.5.0

这次安装一次，以后不用再传文件，也不用反复添加扩展。
需要 Windows 自带 PowerShell 5.1 和 Microsoft Edge，不需要 Codex、Python、GitHub账号或管理员权限。

【这次安装】
1. 把这个ZIP发到质检电脑，右键选择“全部解压缩”。不要直接在压缩包内运行。
2. 双击“安装或升级.cmd”。程序会校验签名，然后把助手放到当前Windows用户的固定目录。
3. 按 Win+R，输入以下路径并回车，可找到要加载的文件夹：
   %LOCALAPPDATA%\WxwQcHelper\extension
4. 在 Edge 打开 edge://extensions/，开启“开发人员模式”。
5. 如果已装旧版助手，先关闭旧版开关，避免两个版本同时运行。
6. 点击“加载解压缩的扩展”，选择第3步的 extension 文件夹。确认版本0.5.0且启用。
7. 在Edge工具栏的扩展菜单中，把“旺销王质检放大助手”固定到工具栏，方便以后应用更新。
8. 刷新旺销王订单扫码页，正常扫描下一张待处理面单。

【以后更新】
1. 维护人员发布新版后，双击桌面的“旺销王助手在线更新”。
2. 程序自动检查公开更新地址，下载、验证、备份并替换本机文件。
3. 提示成功后，点Edge工具栏的助手图标，再点“应用已下载更新”。
   也可到 edge://extensions/ 找到助手点“重新加载”。
4. 刷新旺销王订单扫码页，再正常工作。不需要删除扩展或重新添加。

这是半自动更新：下载和替换自动完成，Edge生效由你点击一次。
请在两单之间更新，不会自动重放扫码，也不会自动刷新正在操作的业务页。
更新依赖质检电脑能访问 GitHub；网络失败时保留原版，可稍后重试。

【回退】
如果新版有问题，双击桌面的“旺销王助手回退上一版”。完成后同样应用扩展更新并刷新业务页。
首次安装还没有旧版本；至少成功更新一次后才能回退。

【文件位置】
助手固定目录：%LOCALAPPDATA%\WxwQcHelper
正式加载目录：%LOCALAPPDATA%\WxwQcHelper\extension
安装完成后可以删除最初解压出来的安装包，但不要删除固定目录。
更新程序只管理这个助手目录，不操作浏览器账号、登录数据或其他扩展。

【更新来源】
独立公开仓库：https://github.com/hxs496061112/wxw-qc-helper
这里仅发布程序和合成测试，不包含订单、备注、账号、密码或Cookie。
版本清单经RSA签名验证，安装包和各文件经过SHA-256校验。

两台电脑可分别安装。每台电脑使用各自的旺销王正常登录。
